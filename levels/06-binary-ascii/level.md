## 故事

后半夜，铺子里的老电报机自己响了起来。它没有喇叭，只有八盏灯一闪一闪，每隔几秒换一个花样。
师傅头也不抬：“它在发一句话，四个大写字母。抄下来，翻译给我听。”

## 知识点

**位与字节**。位（bit）只有 0 和 1 两种取值，就像一盏灯，亮或灭。八位排成一排叫一个字节（byte），能表示 0 到 255。
每一位有自己的权重，从左到右是 128、64、32、16、8、4、2、1。亮着的位把权重加起来，就是这个字节的数值。

**十六进制**。八位二进制太长，所以常把它从中间切成两半，每半四位写成一个十六进制数字：0–9，再加 A–F（代表 10–15）。
例如 `0100 0001`：前半 `0100` 是 4，后半 `0001` 是 1，写成 `0x41`。`0x` 只是在说“后面是十六进制”。

**ASCII**（American Standard Code for Information Interchange，美国信息交换标准代码）。电脑只认数字，所以大家约定了一张表：每个字符对应一个数字。
大写字母 A 是 `0x41`，B 是 `0x42`，一路加一，到 Z 是 `0x5A`。

## 任务

1. 像上一关那样，把 `sketch.ino` 和 `diagram.json` 放进空白工程，点运行。这一关不用改任何东西，电报机是好的。
2. 八盏灯从左到右是 b7、b6 … b0。蓝色四盏是高四位，黄色四盏是低四位。亮=1，灭=0。
3. 每个字节会亮大约 3 秒，字节之间全灭半秒。一共四个字节，然后全灭一阵，再从头来。
4. 把每个字节抄成八位二进制，切成两半，换成两个十六进制数字，到上表里查出字母。
5. 四个字母按出现的先后连起来，就是口令。

## 提示 1

先别急着查表。把第一帧的八盏灯，从左到右写成 0 和 1，写在纸上。

## 提示 2

蓝色四盏是前半，黄色四盏是后半。每半边各算一个数：8、4、2、1 的权重，亮着的加起来。比如 `0100` 是 4。

## 提示 3

四个字节的前半边数字都是 4 或 5，所以十六进制是 `4?` 或 `5?`，落在表的 A–O 或 P–Z 两栏里。算出后半边的数字，再去表里对应那一栏找字母。

## 复盘

这四帧是 `0100 0110`、`0101 0101`、`0101 0011`、`0100 0101`，也就是 `46 55 53 45`，对应 F、U、S、E。

为什么要懂这个：你以后在串口里看到的每一个字符，在线路上其实都是这样一串高低电平。单片机“说话”，说的就是字节。
大写字母的码都在 `0x41`–`0x5A` 之间，小写字母整体比大写大 `0x20`，数字 `0` 到 `9` 是 `0x30` 到 `0x39`，这些规律以后看十六进制转储时很有用。

仿真和真实硬件的差别：这里八盏灯都直接接在引脚上，没有加限流电阻（为了图面清爽），真实电路里每盏灯都要串一个电阻。
真实世界里引脚是稀缺资源，八位数据一般不会占八个引脚，而是用移位寄存器（比如 74HC595）把串行信号展开成八位并行输出。
