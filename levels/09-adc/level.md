## 故事

师傅的旧保险箱上没有数字键盘，只有一个旋钮。他说开锁要把旋钮拧到一个特定的电压，并且在那里停稳两秒。
可是你一接上电，屏幕上显示的电压永远是 0.00，仿佛旋钮是摆设。

## 知识点

**ADC**（Analog-to-Digital Converter，模数转换器）：单片机只认数字，但世界上很多东西是连续变化的，比如旋钮的位置，对应一个 0 到 5V 之间的电压。
ADC 就是把这个电压量成一个整数。Uno 的 ADC 是 10 位的，输出 0 到 1023 之间的整数：0 对应 0V，1023 对应 5V。`analogRead(A0)` 读的就是这个整数。

想知道电压是多少，要把整数换算回去：

```
电压 = 读数 × 5 / 1023
```

电位器（旋钮）其实就是你在第一章见过的分压：滑动触点把总电压按位置分掉一部分，输出到中间那根线上，ADC 量的正是这个分压结果。

C 语言有个坑：两个整数相除，结果还是整数，小数部分直接丢掉。`675 / 1023` 得到的是 0，不是 0.66。要得到小数，至少让其中一个数是小数（浮点数），比如写成 `675 * 5.0 / 1023`。

## 任务

1. 把 `sketch.ino` 和 `diagram.json` 放进空白工程，运行。串口每 0.2 秒打印一行“读数”和“电压”。
2. 试着转动旋钮：点住旋钮的白色圆盘拖动；或者点一下旋钮选中它，再用键盘微调（左右方向键每次加减 1，PageUp、PageDown 每次加减大约 100，Home 回到 0，End 到 1023）。你会发现读数变了，电压却一直不对。
3. 找到代码里换算电压的那一行，修好它。
4. 把旋钮拧到电压约 3.30V（读数大约 675），在 ±0.05V 的范围里保持不动 2 秒。保险箱开了之后，串口会出现 `口令：` 加四位数字。

## 提示 1

先看串口：读数一直在变化，说明 ADC 没问题。可是电压怎么都是 0.00（或者 5.00），不对劲。

## 提示 2

问题在换算的那一行：`raw / 1023 * 5`。`raw` 和 `1023` 都是整数，除出来的小数部分被丢掉了。

## 提示 3

让计算变成浮点：把它改成 `raw * 5.0 / 1023`。`5.0` 是小数，整个算式就按小数来算了。

## 复盘

整数除法把 `raw / 1023` 变成了 0，后面不管乘几都是 0；只有拧到最大（1023）时才会得到 1，再乘 5 得到 5。所以起始工程的电压只会显示 0.00 或 5.00。
改成 `raw * 5.0 / 1023` 之后，先乘再除，并且用了浮点数，3.30V 对应的读数是 675，换算出来是 3.299V。

仿真和真实硬件的差别：Wokwi 里电位器给出的读数是精确的，不会晃。真实的 ADC 读数总会有几个单位的噪声，所以通常要多读几次取平均，或者像这一关一样，要求它在一个范围里“稳定一段时间”才算数。
另外，Uno 的 ADC 参考电压默认是供电电压（5V），供电不是准确的 5.00V 时，换算出来的电压就会有误差；USB 供电的 Uno 经常是 4.8V 左右。

口令是 `8372`。
